## Описание программы

PhUtils - набор простых вспомогательных утилит для обработки записей сигналов.

## Основные особенности

- **Простое управление**: Интуитивно понятные элементы управления
- **Быстрая работа**: Максимально быстро позволяет решить задачу

## Системные требования

- **ОС**: Windows 10/11

## Работа с программой

Все утилиты имеют общий интерфейс.
1. Используйте меню File-->Open для выбора файла. Или перетащите его на окно программы. 
2. Задайте требуемые параметры обработки.
3. Нажмите кнопку Старт для обработки файла.
4. Дождитесь окончания обработки.
5. Готово!

## Состав
### phSplit
Позволяет разбить файл на несколько частей.
**Fragment size** - размер файлов
### phFiltr
Позволяет отфильтровать сигнал.
**SampleRate In** - тактовая оцифровки
**Bandwidth Out** - полоса после фильтрации
**Taps cnt** - параметр фильтра
### phCut
Позволяет отрезать часть файла.
### phSum
Суммирует два файла.
### phFiltrK
Позволяет отфильтровать сигнал, задав коэффициенты фильтра. Для генерации фильтра можно использовать Matlab или GnuRadio.
### phNorm
Нормирует сигнал по уровню.
### phEndian
Меняет порядок бит в байте.
### phHeterodyne
Смещает сигнал по частоте.
### phInv
Инвертирует сигнал.
### phIq2ReIm
Разбивает комплексный сигнал на реальную и мнимую часть и сохраняет их в отдельные файлы.
### phResampler
Позволяет перетактировать сигнал.
### phSlicer
Нарезает сигнал широкой полосы на файлы с меньшей полосой. Есть возможность задать перекрытие.
### phPack
Упаковывает биты в байты.
### phUnpack
Распаковывает байты в биты.
### iq2bin
Конвертирует позиции с выхода демодулятора QPSK в биты.
